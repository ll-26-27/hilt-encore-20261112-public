# The context folder

This folder is written for two readers at once: you, and the AI agent you open this repository with. When Claude Code starts here, it reads `CLAUDE.md`, which points it to this folder. Everything here is public, written for participants in the Learning Lab's talk at the 2026 HILT Encore Event.

A context folder is the move we keep coming back to this year. Our students share theirs with each other so they can work together; we share ours across the Learning Lab so any of us, or any of our agents, can pick up a project. This one is a small, public example of the shape. Copy it, and start one of your own.

## Start here

1. [`using-this-repo.md`](using-this-repo.md): how to open this repo in Claude Code, set up keys (or not), and what to try first.
2. [`learning-lab.md`](learning-lab.md): who the Learning Lab is and how we work.
3. [`the-talk.md`](the-talk.md): the talk in brief, and what we're still wondering.
4. [`tools-and-skills.md`](tools-and-skills.md): what the scripts in `ll-utilities/` and the skills in `.agents/skills/` are for.

## Before you send anything to a model

- [`data-security/`](data-security/): Harvard's data security levels in plain words, with sources, and what they mean for this kit. **The kit's rule: external tools get only public (Level 1) material, never confidential data; use the HUIT APIs for anything sensitive.**
- [`huit/`](huit/): HUIT's AI API gateways (OpenAI, Gemini, Bedrock): what each offers, which data each is approved for, and how a Harvard person gets a key.

## Add your own

Make a folder here for your own project, for example `_context/my-course/`, with a `README.md` that says what it is and what to read first. Put in what you'd tell a new collaborator: the syllabus, your notes, the questions you're working on. Start with public or made-up material; read [`data-security/`](data-security/) before adding anything confidential, and never point an external tool at it.
