# Operations

Numbered steps, run from the repository root, in order: `00` verifies the bundled pages and readings already collected from case 03; `01` builds
the settled layer and anchors its lines (deterministic code); `02`
translates with two models (model judgment, cached); `03` renders the page;
`04` serves it so the page can write to the log. `05-review.md` says how a
person works in the page and how a recorded decision becomes text in a new
build. `work/` is scratch.
