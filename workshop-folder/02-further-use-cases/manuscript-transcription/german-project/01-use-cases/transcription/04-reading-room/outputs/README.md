# Outputs

`index.html` is the reading room, regenerated by `build`. `reading/`
holds the record: `log.jsonl` (every decision, question, issue and excerpt,
append-only), `inbox/` (logs exported from a browser that could not reach
the server), `runs/` (each translation run with its `run.json` and cost)
and `builds/` (each settled layer, immutable, one folder per build id).
