# 1. Turn the observation into a model

Read `../inputs/gened-1104-staff-brief.md` and choose a kitchen observation. Write its start state, end state, changing quantity and units. Identify a governing relationship, each constant and its source, and the assumptions that make it usable. Use `../inputs/model-and-math.md` to inspect the four worked examples.

Write a short model specification in `../outputs/`: equation, input ranges, unit conversions, fixed values, predicted outputs and a hand calculation. Keep calibration separate from validation. In particular, describe the tahini relationship as illustrative.
