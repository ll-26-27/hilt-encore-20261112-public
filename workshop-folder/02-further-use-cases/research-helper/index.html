Research helper / file guide

This example produces an HTML summary and a separate interpretation for each source paper. Read summary.md for the workflow and limitations.

Source review: read the November 12 audit for checked claims and unresolved issues in the supporting materials.

Top-level

  • summary.md — purpose, workflow, and limitations
  • CLAUDE.md — project-level instructions loaded by Claude Code on session start
  • index.md / index.html — this file

inputs/

The source corpus. Currently four papers on long-context attention in LLMs. Numeric filename prefixes are preserved into the outputs.

  • 01_context-rot_hong-troynikov-huber_2025.md
  • 02_lost-in-the-middle_liu_2024.pdf
  • 03_context-length-alone-hurts_du_2025.pdf
  • 14_fully-utilize-context_an_2024.pdf

operations/

  • 01-generate-research-summary-prompt.md — the prompt: read each paper fully, write a faithful neutral summary, then a separate "twist" pass relating findings to the research agenda

outputs/

One HTML summary per source paper, plus an index linking all summaries. Some summaries use local figures in outputs/assets/.

  • outputs/index.html — the hub
  • 01_context-rot_hong-troynikov-huber_2025.html
  • 02_lost-in-the-middle_liu_2024.html
  • 03_context-length-alone-hurts_du_2025.html
  • 14_fully-utilize-context_an_2024.html
  • outputs/assets/ — figures/diagrams referenced by the per-paper HTML

To regenerate: drop new papers into inputs/ (preserve numeric prefixes), then run the prompt at operations/01-generate-research-summary-prompt.md. Existing summaries are overwritten in place; the hub is regenerated to include the new entries.
