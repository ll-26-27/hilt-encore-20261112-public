# 03 · Ask for skills, tied to the paper

**Prompt:**

> Can you also think of Claude SKILL.md files that would be useful? Today we are talking about skills and MCPs, so I'm wondering what could help someone like Mary do her research.

**What came back:** about twenty candidate skills and some MCP ideas, each tied to a page of the paper (`/index-transcript` for Stage 1; `/find-negative-cases` for the Blee, Katz, and Luker requirement on pp. 731–732; `/methods-paragraph` for the opaque-methods problem on pp. 718–719), and a recommended three.

**The move worth noticing:** zoom in on one category and keep the same constraints. A skill tied to a page is a claim someone can check.
