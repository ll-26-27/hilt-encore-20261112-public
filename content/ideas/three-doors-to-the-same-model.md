Do one small task three ways: in the chat window, in the terminal, and through the API, so students see they are one model behind different interfaces.

## How it runs

Pick a task (summarize a page; generate an image). Do it in the chat app; then in a command-line tool; then with a two-line API call. Draw the three doors on the board and name what each is for.

## With Claude

Claude Desktop for the chat door; Claude Code in a terminal for the second; ask Claude Code to "write the smallest script that sends this prompt to the API and prints the answer, with the key read from `.env`" for the third.

## Why it works

It replaces a bewildering market of AI products with a simple schema (a few models, a few interfaces) and makes "it's just a wrapper around the API" something students can see.

## Time and materials

30 minutes. Chat account, terminal, an API key.

## Variations

Compare the same task's cost and speed across the three doors; add a fourth door (a Slack bot).
