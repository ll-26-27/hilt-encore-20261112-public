Test and demonstrate any tool that reads student work with an invented person and invented materials, written to have the problems real material has.

## How it runs

Write a fictional student's project folder with a clear piece, process notes, an unchecked AI summary, a private folder, a venting note, a garbled file. Use it to test tools, to demo them, and to let students practice on before they use their own.

## With Claude

Ask Claude: "Invent a student project folder about [a real public-domain subject] with these files and these planted problems: … Mark everything invented in a README." For voices, macOS `say` reads scripted lines.

## Why it works

It protects real students, and the planted problems make tests meaningful: you know what the tool should catch.

## Time and materials

30 minutes with Claude.

## Variations

An invented patient for clinical reasoning; an invented client for a design brief; an invented dataset with known errors.
