Run a hands-on class as stations that small groups rotate through on a timer, each with a one-page printed card, and keep the long docs online for later.

## How it runs

Pick three to five stations; the instructor demos all of them in ten minutes, then groups of three rotate every 20 minutes. Each card has the goal, three to five steps, the terms to use, and one challenge. Close with each student posting one line: the station that surprised them, and why.

## With Claude

Ask Claude Code to draft each station card as Markdown from your notes, then build a print view that lays each card on one Letter page ("Make `/print/cards` render every file in `stations/` as one printable page each"). The online docs hold the long versions "students don't have to read."

## Why it works

Small groups get hands on equipment, rotation keeps attention fresh, and a card is something people use in the moment, unlike a website.

## Time and materials

90 minutes for four stations. Printer; station materials.

## Variations

Stations by method in a research course (interview, archive, survey, observation); by tool in a software course.
