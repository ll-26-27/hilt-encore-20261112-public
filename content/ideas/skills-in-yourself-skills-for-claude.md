For any technique, decide whether you will learn it yourself by repetition or teach it to the AI as a reusable skill, and do one of each.

## How it runs

Students list the techniques their project needs. For one, they practice it themselves until they can do it without help. For another, they write a Claude skill: a short instruction file that tells Claude how to do it the way they want. They reflect on which was which and why.

## With Claude

In Claude Code, create `.claude/skills/<skill-name>/SKILL.md` with a name, a description of when to use it, and the steps. Ask Claude: "Help me write a skill for <technique>; ask me questions about how I want it done before writing it." Test it on a new example.

## Why it works

It makes students decide, case by case, what is worth internalizing and what can be delegated, and teaches that both require understanding the technique.

## Time and materials

One class session; Claude Code.

## Variations

A class library of skills students can borrow; compare a human-taught and Claude-taught version of the same technique.
