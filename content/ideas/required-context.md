Beside required and optional reading, add a third list: texts students are not expected to read cover to cover but must load into their AI tools while they work.

## How it runs

For each unit, assemble a folder of sources (articles, manuals, transcripts, the syllabus itself) and give it to students as a downloadable folder or repository. Tell them to load it into Claude when they work and ask it questions. In class, ask questions that require going back to the sources, and ask students what they found by asking.

## With Claude

Distribute the folder as a Git repository students clone; in Claude Code the files are in the working folder and Claude can read and search them. Add a short `README.md` map of what's in it and why (a human-written index). In Claude Desktop, add the files to a Project.

## Why it works

It is honest about how students now read, keeps the sources in the loop instead of the model's memory, and lets a course carry far more material than anyone could read, with a human map of what matters.

## Time and materials

An instructor's afternoon per unit to gather and map; storage for the folder.

## Variations

Students add to the pack each week; a "required context" exam where students must find a passage by asking; a pack per student project.
