Alongside any scripts students use, keep one file listing the exact commands that were run for real, with their date and result.

## How it runs

Each time a script is used successfully, add the command to `examples.md`. Students start from a known-good command and change one argument.

## With Claude

Ask Claude Code, after a successful run: "Add this command, today's date, and what it produced to utils/examples.md."

## Why it works

It turns tribal knowledge into a record and gives beginners a safe starting point.

## Time and materials

Seconds per entry.

## Variations

A lab's protocol log; a statistics course's verified code snippets.
