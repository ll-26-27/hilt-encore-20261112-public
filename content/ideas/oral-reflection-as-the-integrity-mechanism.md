When students are required to use AI, grade the work together with the student's spoken account of it: what the tools did, what they did, and why.

## How it runs

State in the syllabus that AI use is required and that "a result you cannot explain or modify is not evidence of learning." Build every graded piece around a recorded explanation (a reflection video, an interview, a final oral reflection). Grade the explanation on specificity: decisions named, alternatives rejected, what the student changed in the AI's output and why.

## With Claude

Before a student's oral account, a Claude Code skill reads the student's project folder (the work, notes, the git history, chat exports) and drafts five questions about key decisions and obstacles; the interviewer picks two. Ask Claude Code for "a skill that reads this repository and lists the five most consequential decisions visible in the history, each with the commit or file where it shows."

## Why it works

It moves assessment from the artifact, which AI can produce, to the student's understanding of it, which it can't. It also makes the integrity rule something students practice rather than something enforced.

## Time and materials

Built into existing assignments; a recording device; optionally Claude Code for question prep.

## Variations

In writing-heavy courses, a short oral defense of one paragraph; in labs, a two-minute account of one design choice at the bench.
