Give the AI one folder on the student's computer, and nothing else, then have it sort a messy pile of files and build a web page of the result.

## How it runs

Each student makes a folder (e.g. `~/AI`), grants Claude access to only that folder, copies in a messy set of downloads or photos, and asks Claude to describe, rename, and organize them, then build an HTML index. Discuss what data should and shouldn't go in.

## With Claude

In Claude Desktop (with folder access) or Claude Code started in that folder: "Look at every file here. Propose a folder structure and new names; wait for my OK; then do it and build `index.html` showing the images as a gallery with captions."

## Why it works

Students experience the power of an AI that reads and writes files, inside a boundary they chose, and practice deciding what to let it touch.

## Time and materials

20 minutes. Claude Desktop or Claude Code.

## Variations

Sort a semester of lecture notes; organize field photos with captions from EXIF data; tidy a dataset folder and write its README.
