Give students two copies of a working tool: an identical one that is theirs to change, and a version someone already changed over a morning, to show how far changes can go.

## How it runs

Students open the remix copy in Claude Code and ask for one change at a time (a new button, a different prompt, a new export), testing after each. They compare with the worked example. Nothing they do can break the original.

## With Claude

Ask Claude Code to copy the tool's folder whole (page, components, server routes, styles, prompts) into `remix/`, so it shares nothing with the original. Students then ask Claude for changes inside that folder only.

## Why it works

Changing a working thing is an easier first step than building from nothing, and the worked example sets an ambitious but real target.

## Time and materials

Minutes to set up; 30 to 60 minutes of student work.

## Variations

A remix copy of a website, a game, a data notebook, a lab protocol.
