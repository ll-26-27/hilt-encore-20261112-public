Before a holiday, students set up a small system of AI agents to keep working (or playing) while everyone is away, then return to read what it produced.

## How it runs

Each group designs a few agents with roles and rules, a budget cap, and a stop condition, and starts them before the break. After the break, they read the log, pick the most interesting moments, and present what the system did and why.

## With Claude

Build with Claude Code a folder-based agent system with a cost ceiling and a log (ask for "three agents with these roles that take turns in a shared log file, at most N turns, with a hard spending limit, writing each turn to logs/<date>.md").

## Why it works

It makes autonomy concrete and inspectable, and the return gives students a large record to analyze.

## Time and materials

An hour to set up; an API budget.

## Variations

Agents that discuss the course readings; agents that maintain a fictional world.
