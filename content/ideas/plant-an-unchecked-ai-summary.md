Put an AI-written summary of a source into a project folder, labeled as unchecked, and see whether the people and agents reading the folder treat it as fact.

## How it runs

Add a file like `secondary/ai-summary-of-<source>.md`, marked "AI summary, not checked against the book". Run the reading (people or agents) and look at the result: did anyone quote it as the source's view? Then check the summary against the source together and correct it.

## With Claude

Ask Claude for a plausible summary of a real book with one subtle misreading, and put it in the folder. Any agent reader (Claude Code on the folder, or a multi-role ensemble) is the test.

## Why it works

It trains the reflex to separate a source from a summary of it. In one agent run, the final briefing told the interviewer not to repeat the AI summary as fact and to ask the student what the book says.

## Time and materials

20 minutes; one book or article the class can check.

## Variations

An unchecked AI translation; an AI-generated citation list with one invented entry; a dataset description that doesn't match the data.
