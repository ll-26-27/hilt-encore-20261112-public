Every button in a teaching tool also shows the equivalent terminal command, so students can do it themselves next time.

## How it runs

Students generate a video (or trim a clip, or resize an image) from a web form, then copy the displayed command into a terminal and run it with one change.

## With Claude

Ask Claude Code to have the page call the same script students can run, and display the exact command line with the user's choices filled in.

## Why it works

It bridges the friendly interface and the underlying tool, so students graduate from one to the other.

## Time and materials

Part of building the tool.

## Variations

A statistics GUI that shows its R code; a database form that shows its SQL.
