Design an activity once and run it several times in a week for different groups, improving it each time.

## How it runs

Run the class version first, then the same setup for a workshop, a drop-in session, or colleagues, changing it each time based on what happened. Keep notes on each run.

## With Claude

Keep the activity as a folder (cards, prompts, tools) and ask Claude Code before each run: "Adapt this for [audience, time]; list what you changed."

## Why it works

Repeated runs refine an activity faster than a single pass, and the variations show what is essential.

## Time and materials

The same materials, reused.

## Variations

Run it first with teaching assistants as a rehearsal.
