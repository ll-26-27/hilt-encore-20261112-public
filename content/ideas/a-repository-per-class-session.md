Give each class session its own small, self-contained repository or site, with its docs, glossary, and tools, that students can open on the day and keep afterwards.

## How it runs

For each session, create a repository with a README, the handout, a glossary of the session's terms, and any small tools the activity needs. Share the link at the start of class. Students clone it or open the site; it stays as a record of the session.

## With Claude

Ask Claude Code: "Make a new repository for this session from last week's: keep the Markdown reader and print styles, clear the content, add this handout and a glossary of these twenty terms, and add a page with <tool>." Publish with GitHub Pages or Vercel.

## Why it works

Each session is a complete, linkable object; students see the pattern of "a folder of context plus the thing you're making," which is the same pattern they use for their own work.

## Time and materials

Thirty minutes to an hour per session once a template exists; GitHub.

## Variations

One repository per unit; students contribute pages back by pull request.
