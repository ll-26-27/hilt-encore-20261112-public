Build every tool that needs a microphone, camera, or interface with a simulated input first, so it can be tested and shown without the hardware.

## How it runs

The tool has a "simulate" button: a pretend reader with mistakes, a fake two-channel voice, a stand-in for an eight-input interface. Students test their design with it, then switch to the real device in the room.

## With Claude

Ask Claude Code: "Before wiring the microphone, add a simulated input that produces [realistic data with errors], and make every test use it."

## Why it works

It separates logic from hardware, makes testing repeatable, and lets a demo survive a missing cable.
