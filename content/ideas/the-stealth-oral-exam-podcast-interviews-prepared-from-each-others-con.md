Students interview each other about their finished projects as a podcast, each host preparing by having Claude read the guest's context folder, so the conversation works as an oral exam that doesn't feel like one.

## How it runs

Each student keeps a context folder for their project: notes, drafts, prompts, process logs, sources, a short description of the piece. After the project is due, students meet in threes for an hour: three 15-minute interviews with rotating roles (host, guest, producer). Before the session, each host opens the guest's folder with Claude and prepares questions about the decisions, obstacles, and what the guest did that the AI couldn't. The producer watches the time and passes the host follow-ups. The recordings are the assessment.

## With Claude

In Claude Code, point a session (or a small set of subagents) at the guest's folder and ask for "key decision points, moments they overcame obstacles, and things they did that Claude couldn't have done without them", and to end with "if you leveled this up into a system, what would you do?" Build it once as a skill so every host gets the same kind of brief.

## Why it works

Because the guest wants to be interviewed well, they put generous, honest context into their folder; the host can only ask good questions if the folder shows the process. Speaking about the work in real time shows what the student has internalized, which an AI-assisted artifact alone can't.

## Time and materials

One hour per group of three; microphones (two or three); Claude Code or Claude Desktop with access to the folders.

## Variations

A one-on-one version with the instructor as host; a dress rehearsal before the graded round; a version where the guest also prepares questions for the host's project; the same design for a thesis defense or lab presentation.
