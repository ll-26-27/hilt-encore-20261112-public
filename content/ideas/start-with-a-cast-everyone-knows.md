Before students design their own ensemble of AI characters, run one made of characters everyone already knows, so the class can hear when a voice is off.

## How it runs

Pick a familiar cast (members of a famous band, characters of an ensemble TV show, the faces on a monument). Run them talking to one another for twenty turns. Students mark lines that sound wrong for a character and say why. Then each designs a cast of their own.

## With Claude

In Claude Code: "Make `systems/cast/` with one Markdown file per character (voice, wants, secrets) and a `system.md` premise; run 20 turns where code picks who speaks next; save the script." The class reads the script aloud.

## Why it works

Familiar characters are a built-in ear test: everyone can judge them, so the class learns to evaluate character and voice before working with casts no one knows.

## Time and materials

30 minutes. Claude Code; an API key (a few cents a run).

## Variations

Historical figures debating; the authors on a syllabus discussing a question; famous scientists reviewing a paper.
