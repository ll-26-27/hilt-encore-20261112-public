When learning a tool or a technique, give the AI the entire manual or documentation and question it, instead of relying on a tutorial or the model's memory.

## How it runs

Before a hands-on session (a camera, a lab instrument, a software library), students download the official manual or API docs and load them into their AI. They ask how to do the specific thing in front of them, ask for the page or section, and check it on the device. Debrief: what did the manual say that the tutorial didn't?

## With Claude

In Claude Code, put the PDF or docs folder in the project (convert PDFs to Markdown first: ask Claude Code "convert this PDF manual to Markdown with headings, one file per chapter"). Then ask: "Using only these files, how do I set custom white balance? Quote the section and give the file and heading." In Claude Desktop, attach the manual to a Project.

## Why it works

It teaches a new way of reading: chasing the source behind the answer, at the moment of need, with citations students can check against the real equipment.

## Time and materials

Ten minutes to set up; the manual; the device or software.

## Variations

Load a field's style guide, a statute, a lab protocol, or a game's rulebook.
