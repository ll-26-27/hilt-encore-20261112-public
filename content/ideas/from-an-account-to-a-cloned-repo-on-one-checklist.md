In the first weeks, walk every student from a GitHub account through a package manager, Git, the terminal, and an AI assistant to the course's repository cloned and open on their own machine, with one page to tick off.

## How it runs

A lab session with the tutorial and the checklist; students help each other; anything that fails becomes a note on the tutorial for next time.

## With Claude

Ask Claude to write the tutorial for your students' machines and test each step; students use Claude Desktop to troubleshoot errors by pasting them in.

## Why it works

Every later idea on this list assumes students can open a folder with an AI assistant in it; doing the setup together early removes that barrier.

## Time and materials

One lab session; laptops; accounts.

## Variations

A data science course's Python environment; a design course's file structure.
