Make the first class a small, real version of every practice the course will use, and let each later session deepen one of them.

## How it runs

List the course's recurring practices (posting work, taking notes, dictating, recording, working in a repository, reflecting aloud). Design day one so each happens once, briefly and for real. In later weeks, name which practice that week thickens.

## With Claude

Ask Claude to read the syllabus and list every recurring practice it implies, then draft a day-one plan with a five-minute version of each.

## Why it works

Nothing on the syllabus is new when it arrives later, so students build on familiar moves, and the first day shows the whole shape of the course.

## Time and materials

Planning time; one class session.

## Variations

A first week instead of a first day; a lab course's first session that touches every instrument once.
