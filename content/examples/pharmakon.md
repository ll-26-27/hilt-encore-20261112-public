## What this is

In Plato's *Phaedrus*, Theuth presents writing as a *pharmakon* for memory and wisdom. Thamus replies using the same word. This explorer follows that exchange through seventeen translations in ten languages, with clickable word choices, side-by-side source passages, and literal English back-translations.

Choose a Greek term, select a translator, and compare two versions. The passages are the translators' words; the classifications and explanatory notes are saved model interpretations.

## How we made it

Built for ENG 298AI on November 3, 2026. The workflow assembled an inventory, downloaded public-domain source texts, located the passage, and extracted each translator's renderings of eight key word positions. Code checked 136 extracted renderings against the passages and flagged one that did not occur verbatim. A model also produced literal back-translations for comparison.

This page uses the original saved data and keeps the source links, edition notes, and check results available. The full original explorer, including its wider inventory and translation experiments, opens from the link below the comparison.
