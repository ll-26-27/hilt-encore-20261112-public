We close on what we learned, and what we're wondering.

It's exciting that we can build individualized learning experiences for students. But then the question you're left with: what's still scarce? (Right now it can seem like everything is scarce because of AI; anyone who's tried to buy a computer lately knows there aren't enough GPUs.)

The just-in-time, disposable app. When the tool serving a community is janky enough that it's easy to vibe code your own replacement, there's no longer one app everyone uses. We used to say in video editing that it's not about the tool, it's about the choices you make; you learned the tool on the way to making interesting choices. Now everyone can build an editing tool fitted to their own intuitions. That's a loss, too: there's no message board for the app you vibe coded. What happens to tool-based knowledge?

Learning a tool may not pay off before the tool changes. It was worth a year to learn Final Cut, because it would pay off for life. Is it worth it for an 18-year-old now?

Learning objectives are moving targets. Why get better at this AI thing? What is there to get better at?
